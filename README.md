# \# 📢 Canal de Ouvidoria

# \## 📌 Sobre o Projeto

O **Canal de Ouvidoria** é um sistema desenvolvido em Python que permite registrar e gerenciar reclamações por meio de um menu interativo executado no terminal.

O projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais da linguagem Python, como estruturas condicionais, estruturas de repetição, listas e manipulação de dados.

# \## 🚀 Funcionalidades

O sistema possui as seguintes funcionalidades:

1\. **Listar Reclamações:** Exibe todas as reclamações registradas.

2\. **Adicionar Reclamação:** Permite cadastrar uma nova reclamação.

3\. **Pesquisar Reclamação:** Busca reclamações por palavras ou expressões.

4\. **Remover Reclamação:** Exclui uma reclamação selecionada pelo usuário.

5\. **Quantidade de Reclamações:** Informa o total de reclamações cadastradas.

6\. **Substituir Reclamação:** Permite editar uma reclamação existente.

7\. **Sair:** Encerra a execução do sistema.

# \## 🛠️ Tecnologias Utilizadas

\- Python 3

\- Estruturas condicionais (`if`, `elif`, `else`)

\- Estrutura de repetição (`while` e `for`)

\- Listas (`list`)

\- Funções de entrada e saída (`input()` e `print()`)

\- Métodos de listas (`append()` e `pop()`)

# \## ⚠️ Observações
\- Os dados são armazenados temporariamente em uma lista.
\- As reclamações não são salvas em banco de dados.
\- Ao encerrar o programa, todas as informações cadastradas são perdidas.
